Backlog Front-end & Design — Migração para Inspinia

Recriação completa da interface do protótipo SIPLAM sobre o template Inspinia (Bootstrap 5). Escopo estrito de front-end e design: nenhuma história de API, banco ou regra de negócio de servidor.

Base: TanStack + shadcn → Inspinia 5

Premissas do escopo

  • O estado continua em localStorage com o mesmo seed de demonstração — as histórias abaixo assumem que o modelo de dados e as funções puras (regras.ts, financeiro.ts, atena.ts) são portados sem alteração de lógica.
  • O template é o Inspinia 5.x em distribuição HTML estática: Bootstrap 5, ícones Tabler, ApexCharts e ECharts, DataTables, Choices.js e Select2, SweetAlert2. São 234 páginas de exemplo e nenhuma etapa de build — o pacote traz apenas o CSS compilado, sem fontes SCSS.
  • Todo componente shadcn/Radix precisa de equivalente Inspinia. A tabela de equivalências no fim do documento é o contrato de conversão.
  • O protótipo atual não tem nenhum gráfico — só tabelas densas. As histórias marcadas novo são acréscimos que o Inspinia viabiliza barato (ApexCharts/Chart.js já vêm no pacote).
  • Prioridade: P0 bloqueia a navegação da demo · P1 compõe a paridade funcional · P2 refino e ganho novo.
